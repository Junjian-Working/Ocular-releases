# Ocular

Ocular is a Windows utility for selecting screen content, reading text and numbers locally, and inspecting, correcting and copying understandable results.

## Release status

Recipient installation and updating are under qualification. There is no supported public installation release yet. Please do not distribute validation candidates as finished software.

The future installer will bundle the application, its local OCR runtime and models. Recipients will not need Python, development tools or publisher credentials. Tested releases will use an authenticated update channel.

This repository is for public binary releases and update metadata. It contains no publisher API keys, signing credentials, personal settings or QA screenshots.
